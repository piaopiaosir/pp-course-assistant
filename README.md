## PP 网课小助手它能做什么--支持但不仅限于

### 🧭 通用功能

- 自动识别超星学习通、知到 / 智慧树、雨课堂，进入对应页面后自动开始
- 悬浮球 / 贴边胶囊两种收起形态，支持自动最小化
- 面板缩放 100% / 125% / 150%，手机、平板可用
- 运行日志、答题记录、token 使用查询
- 解除页面复制 / 右键限制，复制题干更顺手
- 自动检测脚本新版本

### 📘 超星学习通

- 视频自动播放，默认静音
- 视频 / 音频自动播放，支持自动倍速、手动倍速
- 模拟播放：不真实播放视频，不消耗流量
- 视频内弹题自动处理，可在设置中关闭
- 章节任务点自动切换
- 文档、PPT、书籍阅读任务自动完成
- 章节测验、作业、考试自动答题
- 全题型支持（如遇到不支持的题目可反馈）
- 人脸识别检测与等待
- 复习模式、仅视频、仅答题、正常模式

### 🌳 知到 / 智慧树

- 视频自动播放，默认静音
- 适配共享课、智慧课程、融合课、卡片课等新版页面
- 支持H5 作业考试，新形态作业考试、掌握度、AI掌握度等
- 逐题查询、自动填涂；不自动提交，请检查后手动交卷
- 弹题自动作答，可关闭
- 可忽略「习惯分」等学习提示弹窗
- 章节测验、作业、考试自动答题
- 支持单选、多选、判断、填空、简答蹬（如遇到不支持的题目可反馈）
- 复习模式、仅视频、仅答题、正常模式

### 🎓 雨课堂

- 视频自动播放，默认静音
- 手动倍速、自动倍速、突破倍速（最高 8x）
- 支持数字人视频
- 课件、图文任务自动完成，讨论任务自动评论
- 作业自动提交
- 考试整卷自动作答，只填答案不交卷，交卷请自己确认
- 遇到风控验证码、确认弹窗会挂起等待，处理完自动继续
- 支持单选、多选、判断、填空、简答蹬（如遇到不支持的题目可反馈）
- 复习模式、仅视频、仅答题、正常模式

### 🤖 AI 问答

- 独立的 AI 对话页签，和答题互不影响
- 支持 Claude、ChatGPT、Gemini、DeepSeek 等多款模型
- 深度思考、联网搜索、多会话、Markdown、参考来源
- 可随时停止生成，适合问知识点、写作思路、代码问题

### 📚 题库与答题

- 三种模式：正常模式、答案校验、AI 模式
- 跳过已答、相似匹配、模拟延迟、答题间隔、正确阈值
- 题库 + AI 双重校验，降低「题库没有 / 答案不一致」的影响
- 题库与模型为第三方服务，服务可能产生费用

## 🚀 三步开始

1. 安装 **Tampermonkey** 或 **ScriptCat** 扩展，再安装本脚本
2. 打开课程平台，右侧出现悬浮球；点开面板，在「配置」里填写题库 / AI 需要的 token
3. 进入章节、作业或考试页面，脚本会自动开始

> 提示：第一次使用，建议先跑一节短课，确认播放、进度、日志都正常，再开自动切换和批量任务。

## 🎯 答题怎么选

| 模式 | 做什么 | 适合 |
|---|---|---|
| 正常模式 | 只查题库 | 题库覆盖率高、想节省答题次数 |
| 答案校验 | 题库 + AI 同时查询并交叉校验 | 正确率优先，消耗约为正常模式的多倍 |
| AI 模式 | AI 直接作答，可开启联网搜索 | 题库没有的题、需要理解或推理的题 |

- 正常模式对于单选 多选 判断题有AI复查答案，如题库答案被AI认定为错误将不会填写，您可使用校验模式，ai模式跳过答案复查
- 校验模式仅支持 单选 多选 判断 题库，其余题型自动降级AI模式查询

几个常用参数：

- **正确阈值**：自动提交的门槛，填涂率 ≥ 阈值才提交；低于阈值只暂存或提示手动补答
- **跳过已答**：已经有答案的题不再请求题库 / AI
- **相似匹配**：题干与题库不完全一致时，按相似度匹配
- **模拟延迟 / 答题间隔**：放慢操作节奏，避免过于机械

## 💡 使用建议

- 同一页面只保留一个网课类脚本，避免同时接管播放器或按钮
- 考试和作业页面通常只填涂，不自动交卷，请检查后手动保存 / 交卷
- 模拟播放和突破倍速有进度清零风险，按自己的课程情况使用
- 人脸识别不会自动绕过，检测到后需要手动完成
- 浏览器最小化、休眠或长时间切后台，任务可能暂停，建议保持页面在前台

## ❓ 常见问题

| 问题 | 说明 |
|---|---|
| 面板不出现 | 确认脚本已启用、页面在支持域名内；刷新页面，并暂时关闭其他网课类脚本 |
| 填了 token 不答题 | 点一下面板空白处或刷新页面，让配置生效；再检查答题模式与正确阈值 |
| 视频倍速被禁用 | 脚本会自动退回 1x，保证任务点正常完成，不要强行突破 |
| 考试会自动交卷吗 | 不会，考试页面只填涂，请手动检查后交卷 |
| 雨课堂能答题吗 | 暂不支持，当前只处理视频、课件、讨论任务 |
| 题库搜不到答案 | 切换到「AI 模式」或「答案校验」，也可手动复制题干搜索 |
| 进度环不动 | 确认已进入视频 / 音频页面；模拟播放的进度在主页信息里查看 |
| 面板挡住页面 | 收成悬浮球 / 贴边胶囊，或在配置里调整 UI 缩放 |
